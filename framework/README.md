# ignibyte/aic-framework

AIC's runtime: a PHP 8.5 framework for agent-written, server-rendered sites, one namespace per
system under `AIC\`, compilable to a native binary with the elephc compiler fork.

```sh
composer require ignibyte/aic-framework
```

The architecture an app's agent reads is [docs/README.md](docs/README.md).

This repository is a read-only split of `framework/` in
[Ignibyte/aic-nextgen](https://github.com/Ignibyte/aic-nextgen), made on each release tag.
Issues and pull requests go there. MIT licensed.
